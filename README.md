## Descripción del trabajo

Diseño e implementación de una base de datos relacional para un **centro médico** que gestiona pacientes, médicos, consultas, recetas y tratamientos. El trabajo se divide en tres partes:

1. **Bases de datos:** clasificación de la base de datos, modelo conceptual (diagrama entidad-relación en notación de Chen), mapeo al modelo relacional (notación Crow's Foot) y análisis de formas normales.
2. **SQL:** resolución de 20 consignas sobre la base de datos provista, ejecutadas en PostgreSQL.
3. **Manejo de versiones:** organización del trabajo con Git y GitHub (commits, ramas y Pull Requests).
